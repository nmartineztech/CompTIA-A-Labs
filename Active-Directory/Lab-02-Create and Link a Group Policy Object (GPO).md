# Create and Link a Group Policy Object (GPO)

## Overview

This lab focused on creating a new Group Policy Object (GPO), linking it to specific Organizational Units (OUs), and applying a security template to those computers.

## What I Did

* Opened **Group Policy Management**.
* Created a new Group Policy Object named **Temp Workstation Settings**.
* Linked the GPO to:

  * **TempMarketing**
  * **TempSales**
* Edited the new GPO.
* Imported the **ws_sec.inf** security template into the **Security Settings** section of the policy.

## Skills Practiced

* Creating Group Policy Objects
* Linking GPOs to Organizational Units
* Managing Group Policy in Active Directory
* Importing security templates
* Windows Server administration

## Outcome

The new Group Policy Object was successfully created, linked to the required Organizational Units, and configured with the imported security settings.
