# Lab-04 – Configure Windows Firewall

## Objective

In this lab, I practiced configuring Windows Defender Firewall and managing firewall rules for different types of network traffic. The goal was to make sure the firewall was enabled while allowing specific services through the Public network profile.

## Skills Practiced

* Windows Defender Firewall
* Windows security configuration
* Firewall profile management
* Managing inbound firewall rules
* Allowing specific network services
* Public network security
* Windows administrative tools

## Environment

* Windows operating system
* Windows Defender Firewall
* Windows Firewall settings
* Public network profile

## Scenario

In this lab, I was responsible for configuring Windows Defender Firewall to protect the computer while allowing specific services that were required for network communication. I enabled the firewall and configured the necessary rules for the Public network profile.

## Tasks Performed

### 1. Enabled Windows Firewall

* Opened the Windows Firewall settings.
* Verified the firewall configuration.
* Turned Windows Defender Firewall on to provide network protection.

### 2. Configured Firewall Rules

I configured the Public network firewall profile to allow the required services:

* Key Management Service
* Cloud Identity
* File and Printer Sharing

These services were allowed through the Public firewall profile as required by the lab.

## Best Practices Followed
* Kept Windows Defender Firewall enabled.
* Applied firewall rules only to the required network profile.
* Allowed only the services specified by the task.
* Used Windows security settings to manage firewall access.
* Maintained firewall protection while allowing required network functionality.

## What I Learned

This lab gave me hands-on experience working with Windows Defender Firewall. I learned how to enable the firewall and manage individual firewall rules to control which services are allowed to communicate through the network.

I also learned why firewall profiles are important. A computer connected to a Public network should have stronger security controls than a trusted Private network. Configuring specific firewall rules allows necessary services to function while still maintaining network protection.
