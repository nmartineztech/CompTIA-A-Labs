# Configure Remote Desktop

## Objective

Configured a Windows computer to allow Remote Desktop (RDP) connections and verified remote access from another Windows computer.

## What I Completed

### Step 1: Enabled Remote Desktop

- Signed in to the target computer using an administrator account.
- Opened **System** from the **Start** menu.
- Navigated to **Remote Desktop** under **Related settings**.
- Enabled **Remote Desktop** and confirmed the change.

### Step 2: Signed Out

- Signed out of the target computer after enabling Remote Desktop.

### Step 3: Established a Remote Connection

- Signed in to a second Windows computer.
- Opened **Remote Desktop Connection**.
- Entered the hostname of the remote computer.
- Selected **Connect**.
- Entered administrator credentials when prompted.
- Successfully established a Remote Desktop (RDP) session.

## Verification

- Successfully enabled Remote Desktop on the target computer.
- Successfully connected to the remote computer using Remote Desktop Connection.
- Verified the remote desktop session opened without issues.
- Closed the Remote Desktop session after confirming connectivity.
