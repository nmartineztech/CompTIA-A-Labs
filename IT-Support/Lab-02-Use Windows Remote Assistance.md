# Use Windows Remote Assistance

## Objective
Used Windows Remote Assistance to connect to another computer and provide remote support.


## What I Completed

### Step 1: Connected to the VPN

- Signed in to the user computer.
- Connected to the VPN.
- Confirmed the VPN connection was active.

### Step 2: Sent a Remote Assistance Invitation

- Opened **Windows Remote Assistance**.
- Chose to invite someone to help.
- Sent the invitation by email.
- Saved the connection password and shared it separately.

### Step 3: Opened the Invitation

- Signed in to the technician computer.
- Opened the email invitation.
- Opened the invitation file.
- Entered the connection password.

### Step 4: Accepted the Connection

- Returned to the user computer.
- Accepted the Remote Assistance connection.

### Step 5: Requested and Allowed Control

- Requested control from the technician computer.
- Allowed the control request on the user computer.
- Verified the remote session was working.


## Result
Successfully established a Windows Remote Assistance session and allowed the technician to remotely control the user computer.
