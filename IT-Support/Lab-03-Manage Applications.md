# Manage Applications

## Objective

Configured Windows applications by controlling startup programs and adjusting settings to support an older application.

## What I Completed

### Step 1: Managed Startup Programs

- Opened **Task Manager**.
- Viewed the **Startup apps** section.
- Disabled programs that were not needed when Windows starts:
  - Compy DVD Apps
  - DIRE Event Monitor
  - inTune
  - SM66 Win32 Utility

### Step 2: Adjusted Application Compatibility Settings

- Opened **File Explorer** and located the application files.
- Opened the application's **Properties**.
- Changed settings in the **Compatibility** tab.
- Configured the application to:
  - Run using **Windows 8 compatibility mode**.
  - Use **640 × 480 display resolution**.
  - Always run with **administrator privileges**.
- Applied and saved the changes.

## Result
Completed application management tasks by reducing unnecessary startup programs and configuring an older application to run correctly on Windows.
