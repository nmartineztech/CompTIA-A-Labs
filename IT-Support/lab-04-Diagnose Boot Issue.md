# Diagnose Boot Issue

## Objective

Troubleshot a Windows startup problem by identifying the cause and repairing the system so it could boot normally.

## What I Completed

### Step 1: Reviewed the Support Ticket

- Opened the ticketing system.
- Located the ticket related to the laptop startup issue.
- Claimed the ticket and reviewed the reported problem.

### Step 2: Diagnosed the Boot Problem

- Started the laptop and confirmed that Windows was not starting correctly.
- Used Windows recovery tools to troubleshoot the startup issue.

### Step 3: Repaired the Startup Process

- Accessed the Windows recovery options.
- Selected the repair tools.
- Ran **Startup Repair** to scan and fix boot problems.
- Allowed the repair process to complete.

### Step 4: Verified the Resolution

- Restarted the laptop after the repair.
- Confirmed that Windows loaded successfully.
- Verified that the user was able to sign in.

### Step 5: Updated the Ticket

- Documented the troubleshooting steps performed.
- Recorded the resolution.
- Closed the ticket after confirming the issue was fixed.


## Result

Successfully repaired a Windows boot issue and restored normal system startup.
