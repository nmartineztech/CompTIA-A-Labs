# Lab – Configure a VPN Connection

## Objective
In this lab, I practiced setting up and connecting to a VPN using Windows network settings. The goal was to configure a secure remote connection and apply the correct authentication and security settings.


## Skills Practiced

* Configuring VPN connections in Windows
* Setting up remote network access
* Configuring SSTP
* Configuring VPN authentication
* Using EAP-MSCHAP v2
* Managing Windows network settings
* Troubleshooting VPN connections

## Environment

* Windows operating system
* Windows Network & Internet settings
* VPN connection
* Remote VPN server

## Scenario

For this lab, I was tasked with creating a VPN connection for a user who needed to securely connect to a remote network. I configured the VPN connection, selected the required connection type and authentication method, adjusted the security settings, and then connected to the VPN to verify that everything was working correctly.


## Tasks Performed

### 1. Created the VPN Connection

* Created a new VPN connection in Windows.
* Named the connection **SalesVPN**.
* Entered the required VPN server address.
* Selected **SSTP** as the VPN type.
* Configured the connection to use a username and password.
* Chose not to save the user's sign-in information.

### 2. Configured VPN Security

* Opened the security settings for the VPN connection.
* Configured the VPN to use **Extensible Authentication Protocol (EAP)**.
* Selected **EAP-MSCHAP v2** for authentication.
* Reviewed the settings to make sure the VPN was configured correctly.

### 3. Connected to the VPN

* Selected the newly created VPN connection.
* Entered the required user credentials.
* Connected to the VPN successfully.
* Verified that the VPN connection was established.

## Best Practices Followed

* Used the required VPN protocol and authentication method.
* Followed the organization's security requirements when configuring the VPN.
* Avoided saving sensitive login information.
* Reviewed the VPN security settings before connecting.
* Verified that the connection worked successfully after configuration.


## What I Learned

This lab gave me hands-on experience setting up a VPN connection in Windows. I learned how VPNs are used to provide secure remote access and how different authentication methods help verify a user's identity.

I also gained practical experience configuring **SSTP** and **EAP-MSCHAP v2**. This helped me better understand how VPN connections are configured in a Windows environment and the importance of using the correct security settings when providing remote network access.
