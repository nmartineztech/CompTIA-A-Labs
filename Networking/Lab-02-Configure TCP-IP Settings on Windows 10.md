# Lab 02 – Configure TCP/IP Settings on Windows 10

## Objective
In this lab, I practiced configuring TCP/IP settings on a Windows 10 computer. The goal was to configure the **Marketing6** computer to connect to the corporate network and access the Internet using a static IP address. I also configured a second network adapter for a separate testing network that would be used for future lab activities.

## Skills Practiced
* Windows 10 network configuration
* TCP/IP settings
* Static IP addressing
* IPv4 configuration
* Subnet masks
* Default gateways
* DNS configuration
* Network adapter configuration
* Configuring multiple network adapters
* Network connectivity troubleshooting

## Environment

* Windows 10
* Marketing6 computer
* Corporate network
* Secondary network adapter
* Static IP configuration
* Separate testing network

## Scenario

In this lab, I worked in the role of an IT administrator supporting a small corporate network. The **Marketing6** computer was running Windows 10 and needed to connect to the corporate network and the Internet using a static IP address.

The computer also had a second network adapter installed. This adapter was intended to connect to a separate testing network at a later time.

My task was to configure the appropriate network settings so the Marketing6 computer could communicate with the corporate network while keeping the second network adapter available for future testing.

## Tasks Performed

### 1. Configured the Corporate Network Connection

* Accessed the Windows 10 network adapter settings.
* Identified the network adapter used for the corporate network.
* Opened the TCP/IPv4 configuration settings.
* Configured the required static IP address.
* Configured the appropriate subnet mask.
* Configured the default gateway.
* Configured the required DNS server settings.
* Reviewed the configuration to ensure the settings matched the network requirements.

### 2. Configured the Testing Network Adapter

* Located the second network adapter installed on the computer.
* Reviewed its network configuration.
* Configured the adapter for the separate testing network as required.
* Kept the testing network connection separate from the primary corporate network.

### 3. Verified Network Connectivity

* Reviewed the TCP/IP configuration after making changes.
* Confirmed that the correct network adapters were configured.
* Verified communication with the local corporate network.
* Confirmed Internet connectivity.
* Verified that the second network adapter was available for future testing.

## Best Practices Followed
* Used static IP addressing as required by the corporate network.
* Verified IP configuration before testing connectivity.
* Configured the appropriate network adapter for each network.
* Kept the corporate and testing network connections separate.
* Reviewed IP address, subnet mask, default gateway, and DNS settings for accuracy.
* Verified network connectivity after configuration.

## What I Learned
This lab improved my understanding of how to configure TCP/IP settings on a Windows 10 computer using a static IP address. I practiced configuring network adapters and learned how the **IP address, subnet mask, default gateway, and DNS settings** work together to provide network connectivity.

I also learned how a computer can use multiple network adapters to connect to different networks. In this scenario, the second adapter was configured for a separate testing network, demonstrating how IT administrators can manage multiple network connections while keeping network environments separate.
